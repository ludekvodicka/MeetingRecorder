# Code of conduct

## The short version

Be civil. Assume the other person is trying to help. Discuss the code, not the person.

## What is not acceptable

Harassment, personal attacks, insults, and unwelcome attention of any kind. Publishing someone
else's private information. Sustained disruption of a discussion.

## Scope

This applies to issues, pull requests, discussions and anything else in this repository, and to
anywhere someone is representing the project.
